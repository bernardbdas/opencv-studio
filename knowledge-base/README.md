# OpenCV Studio Knowledge Hub

Welcome to the unified **OpenCV Studio Knowledge Hub**! This directory serves as a central repository for advanced computer vision guides, deep learning setups, custom GPU benchmarking, and real-time YOLO version comparisons.

All articles are formatted according to the **Google Open Knowledge Format (OKF) v0.2** standards and optimized for Obsidian linkage.

## Articles Directory

*   **[[Project_Architecture_and_Technologies]]**  
    Detailed overview of the project's technical stack: uv, Nx, Bun, xy, FastAPI, React, and Three.js.
*   **[[YOLO_Architectures]]**  
    A comprehensive deep dive comparing YOLOv8, YOLOv9, YOLOv10, and YOLOv11 models, including performance tradeoffs, real-time speed vs. parameter constraints, and task coverage (object detection, instance segmentation, and pose tracking).
*   **[[Computer_Vision_Fundamentals]]**  
    Theoretical explanations of traditional computer vision filters, including Canny edge detection, Harris corner response, custom image resizing interpolation (linear vs. nearest-neighbor), and color-space conversions.
*   **[[AR_Filters_and_MediaPipe]]**  
    Explanations of dynamic facial landmark meshes, coordinate homography mapping for ArUco tag projections, HSV color keying (for invisibility cloaking), and hand landmark tracking for gesture-based filter cycling.
*   **[[UNet_and_CUDA_Kernels]]**  
    Documentation on custom deep learning architectures (U-Net) and optimization methods, including custom C++ CUDA kernel execution and parallel GPU benchmark loops.
